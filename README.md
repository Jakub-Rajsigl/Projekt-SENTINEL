## 💡 O Projektu

**SENTINEL** je vysoce přístupná webová aplikace navržená pro okamžité rozpoznání, překlad a hlasité předčítání textu z jakýchkoliv tištěných i psaných obrázků. 

Primárně slouží k odstranění jazykových i fyzických bariér — ať už potřebujete rychle přeložit cizojazyčný dokument z papíru, ceduli na cestách, nebo si nechat text pohodlně přečíst v plynulé češtině.

---

## ✨ Hlavní Funkce

* 🖼️ **OCR Optické Rozpoznávání Znaků:** Klientské skenování textu přímo z obrázků (`.png`, `.jpg`, `.jpeg`, `.webp`) pomocí Tesseract.js.
* 🌐 **Inteligentní Překlad do Češtiny:** Automatický sémantický překlad jakéhokoliv ze 16 evropských jazyků do přirozené a plynulé češtiny.
  * Okamžité zastavení čtení na jedno kliknutí.
* 🎨 **Cyber-Glassmorphism Design:** Futuristické, responzivní a plynule animované uživatelské rozhraní inspirované moderními tech produkty.
* 🌍 **Podpora 16 Evropských Jazyků:** Včetně přehledné grafické mřížky s ikonami vlajek jednotlivých států.

## 🛠️ Použité Technologie

* **Frontend:** React 18, Tailwind CSS (vylepšený o custom neony a skleněné efekty)
* **OCR Engine:** Tesseract.js v5
* **Překladatelské rozhraní:** Google Translate API & MyMemory Fallback Engine
* **Hlasový výstup:** Web Speech API + ElevenLabs TTS API
* **Deployment:** GitHub Pages
